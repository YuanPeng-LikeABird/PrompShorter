# PromptShorter

## 目的

缩短给大模型的提示词，减少输入Token数量

## 设计

1. 去噪

删除无意义的习惯用词：请问、请帮我等

删除多余的空格、换行符等

删除重复的句子、标点符号等

2.基于词性和词义的简化：

分词后，如下操作：

（1）同义词替换

例：因为/由于 => 因，并且/而且 => 且

（2）重复词删除

例：访问用户中心，根据用户中心返回的结果 => 访问用户中心，根据返回的结果

机器A和机器B并发访问 =>机器A和B并发访问

（3）修饰词删除

删除一些不重要的修饰词，情况非常多，有待持续完善

例: 根据已有的数据 => 根据数据

详细说明 => 说明

综合考虑 => 考虑

以上3种情况 => 以上情况

你是一名资深程序员 => 你是资深程序员
